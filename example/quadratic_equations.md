# Quadratic Equations - Example Material

## Topic
Solving quadratic equations of the form ax² + bx + c = 0

## Key Concepts

### 1. Standard Form
A quadratic equation is written as:
**ax² + bx + c = 0**
where a, b, c are real numbers and a ≠ 0.

### 2. The Quadratic Formula
The solutions are given by:
**x = (-b ± √(b² - 4ac)) / 2a**

### 3. Discriminant
The expression **Δ = b² - 4ac** determines the nature of roots:
- **Δ > 0**: Two distinct real roots
- **Δ = 0**: One real root (repeated)
- **Δ < 0**: Two complex conjugate roots

### 4. Factoring Method
When the quadratic can be factored:
**ax² + bx + c = a(x - r₁)(x - r₂)**
where r₁ and r₂ are the roots.

### 5. Completing the Square
Rewrite as:
**a(x + b/2a)² + (c - b²/4a) = 0**

## Example Problems

### Example 1: Simple Factoring
Solve: x² - 5x + 6 = 0
- Factors: (x - 2)(x - 3) = 0
- Solutions: x = 2, x = 3

### Example 2: Using Quadratic Formula
Solve: 2x² + 3x - 2 = 0
- a = 2, b = 3, c = -2
- Δ = 3² - 4(2)(-2) = 9 + 16 = 25
- x = (-3 ± √25) / 4 = (-3 ± 5) / 4
- Solutions: x = 1/2, x = -2

### Example 3: Complex Roots
Solve: x² + 4x + 5 = 0
- a = 1, b = 4, c = 5
- Δ = 16 - 20 = -4
- x = (-4 ± √(-4)) / 2 = (-4 ± 2i) / 2
- Solutions: x = -2 + i, x = -2 - i

## Practice Tips
1. Always check if factoring is possible first (faster)
2. Calculate discriminant to know what type of roots to expect
3. Verify solutions by substituting back into original equation
4. For complex roots, remember they come in conjugate pairs
